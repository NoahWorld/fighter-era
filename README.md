# 霓虹航线 · NEON WING

原生 Canvas 竖屏自动射击小游戏。共享一套战斗引擎和画面，提供浏览器试玩入口与微信小游戏入口，无第三方运行依赖、无外部图片或字体。

## 浏览器试玩

需要 Node.js 18 或更新版本。在项目目录运行：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。通过 `PORT=4174 npm start` 可指定端口。服务只监听本机 `127.0.0.1`；端口冲突会明确报错，不会自动换端口。仅提供游戏所需静态资源，拒绝目录穿越请求。

点击「即刻起飞」后，按住画面任意位置相对拖动战机；手指不会让战机瞬移，松手仍持续开火。电脑也可使用方向键或 WASD，P / Escape 暂停与继续。使用 Tab 可访问画面上的真实按钮，Enter / 空格激活；焦点有可见描边。

浏览器音效默认关闭，点击「音效 · 关」开启。声音通过用户操作启动 Web Audio；不支持音频时会显示诊断提示。切换窗口或页面隐藏会暂停，回到游戏后需手动继续。

正常帧间隔在 0.25 秒以内时，完整保留实际经过的时间，由引擎细分计算，避免低帧率导致游戏变慢。单帧停顿超过 0.25 秒时会明确提示、暂停战斗并重置计时，需手动继续；浏览器和微信入口遵循同一规则。

## 内容

- 三关：星港外围、碎星航道、核心防线。
- 自动射击、敌机编队、弹幕、首领、掉落道具与战机受伤反馈。
- 过关后选择扩散火力、极速机炮或装甲补给，再进入下一关。
- 胜利、失败与重新开始流程；最高分保存于当前浏览器或微信本地存储。

单关约 40–60 秒是设计目标。简单自动避弹模拟在 3 个随机种子下的三关总通关时间约 133–138 秒；这是自动模拟，不代表真人体验，真实难度和时长仍需玩家试玩测量。当前版本为本地单机原型，没有排行榜服务器、登录、广告、支付或在线联机。

## 微信开发者工具

1. 使用微信开发者工具导入本项目，项目类型选择「小游戏」。
2. 将 `project.config.json` 中的 `touristappid` 替换为自己的真实小游戏 AppID。占位值仅用于提供可编辑的项目配置，不能代替发布身份。
3. 入口是根目录 `game.js`，竖屏设置在 `game.json`。不需要先运行浏览器服务器。
4. 在开发者工具及真机上检查触摸、屏幕比例、安全区域、前后台暂停和帧率。

微信入口使用 `wx.createCanvas`、`wx.getWindowInfo`、触摸事件、本地存储和生命周期 API。按实际屏幕尺寸等比缩放并保留黑边；输入通过同一变换映射到 405 × 720 的逻辑坐标。只跟踪第一根有效手指，按钮优先，点击按钮后继续按住不会误拖战机。

**微信版当前没有音频。微信开发者工具编译、真机兼容和平台发布审核尚未验证，浏览器可运行不等于已通过微信验证。** 当前运行环境如果缺少所需 API，将明确显示错误并停止，不伪装成功。

## 验证与排错

```sh
npm run check
npm test
```

`check` 检查 JavaScript 语法，`test` 运行 16 项引擎测试和 3 项微信 API 模拟测试。浏览器已检查开始、相对拖动、自动射击、暂停，以及 320 / 390 / 647 像素宽度下的布局。微信 API 模拟覆盖低帧率计时、触摸、前后台切换和异常长帧暂停，不代表真实微信渲染或设备兼容验证。

浏览器控制台中可通过 `window.neonWing.game` 检查状态、分数、敌机与弹幕，通过 `window.neonWing.renderer` 检查绘制对象。微信可查看 `GameGlobal.neonWing`。严重错误会停止主循环并弹窗，日志包含当前状态、关卡和分数；存储或音频不可用会给出明确诊断，不会静默丢弃异常。

## 文件

- `src/engine.js`：与平台无关的状态、碰撞、敌人及关卡逻辑。
- `src/renderer.js`：405 × 720 逻辑尺寸下的 Canvas 绘制与按钮布局。
- `src/browser.js`：浏览器输入、像素比例、音频、存储、暂停和可达性按钮。
- `index.html` / `style.css`：桌面飞行面板与手机适配。
- `game.js`：微信输入、屏幕映射、存储与生命周期。
- `server.js`：只监听本机的静态试玩服务器。
- `tests/`：无依赖自动化测试。
