# 战机时代 · FIGHTER ERA

公开仓库：[NoahWorld/fighter-era](https://github.com/NoahWorld/fighter-era)，默认分支为 `main`。

原生 Canvas 竖屏自动射击小游戏。击破敌机获得经验，永久提升等级、火力和装甲，让战机逐步进化。浏览器与微信小游戏共享一套引擎和画面，使用用户提供的本地透明图集，无第三方运行依赖或远程图片、字体请求。

## 浏览器试玩

需要 Node.js 18 或更新版本。在项目目录运行：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。通过 `PORT=4174 npm start` 可指定端口。服务只监听本机 `127.0.0.1`；端口冲突会明确报错，不会自动换端口。仅提供游戏所需静态资源，拒绝目录穿越请求。

点击「驾驶战机出击」后，先观看 3.2 秒飞行员登机、座舱合拢和起飞动画；进入战斗后按住画面任意位置相对拖动战机；手指不会让战机瞬移，松手仍持续开火。点击右侧「救援」「轰炸弹」使用技能，每关各一次。电脑也可使用方向键或 WASD，R 呼叫救援、B 使用轰炸弹、P / Escape 暂停与继续。使用 Tab 可访问画面上的可用按钮，Enter / 空格激活；焦点有可见描边。

浏览器音效默认关闭，点击「音效 · 关」开启。声音通过用户操作启动 Web Audio；不支持音频时会显示诊断提示。切换窗口或页面隐藏会暂停，回到游戏后需手动继续。

正常帧间隔在 0.25 秒以内时，完整保留实际经过的时间，由引擎细分计算，避免低帧率导致游戏变慢。战斗、登机或弹射状态下单帧停顿超过 0.25 秒时会明确提示、暂停战斗并重置计时，需手动继续。菜单、升级选择和结果等非战斗状态没有战斗推进，较长的调度间隔只重置计时，不作为故障提示；浏览器和微信入口遵循同一规则。

## 内容

- 每次出击包含 100 关，分为 10 个星域，每星域 10 关：星港边境、碎星航道、赤焰星云、环星禁区、幽蓝星河、暗影星带、恒星熔炉、极光星域、虚空裂隙、核心决战。
- 星空、远景行星与蓝银战机画面；每个星域使用不同的配色与行星。星点与天体分层向下滚动、离屏循环，体现战机前进。背景复用固定数量的图形，不增加大图资源；暂停时停止滚动。敌人包括红色敌机、战舰（`warship`）和敌对行星（`planet`）。
- 自动射击、敌机编队、弹幕、首领、掉落道具与战机受伤反馈。新增 10 款红色战机、10 款红色战舰；BOSS 交替使用战机与战舰形态，含三种攻击模式。左侧生命条保持固定高度，用比例与数值表达成长后的生命值。
- 呼叫救援后，两架友机飞入编队并自动射击，8 秒后撤离（包含进出场）；暂停和切后台会冻结援军计时。过关或己方被击败后援军结束行动，下一关补充次数。
- 轰炸弹立即击败画面内敌人，包括 BOSS，并清除敌方弹幕；我方战机、援军、已有增益、拾取道具及击杀掉落保留。正常计分和获得永久经验。全屏冲击波短暂显示，结算时正常消退，下一关补充一枚。
- 每次开局和重新出击都有飞行员跑向战机、跳入座舱、起飞的动画。装甲耗尽后先播放 2.6 秒飞行员弹射逃生，再出现「我方战机已被击败」结算。动画期间战斗冻结，暂停或切后台后可从原处继续。动画用 Canvas 轻量绘制，复用现有战机图集。
- BOSS 登场时屏幕边缘柔和闪红三次，持续 2.4 秒，并显示「BOSS 出现」；击败后明确显示「BOSS 已击败」，最后一关显示「最终 BOSS 已击败」。
- 过关后选择扩散火力、极速机炮或装甲补给，再进入下一关。极速机炮的射击间隔最低为 0.07 秒，达到上限后增加 0.4 伤害，选择说明随之变化。后期敌人移动、弹速、波次间隔与 BOSS 射击间隔有边界，关卡数量不会令射速无限增长。
- 击破敌机获得累计经验，等级跨局保留。等级提升会增强火力与生命上限。
- 十款战机外观在 Lv.1–10 逐级解锁；四个成长称号保留为 Lv.1「游隼」、Lv.3「破晓」、Lv.6「雷霆」、Lv.10「星曜」。之后等级仍可继续增长，保持第十款外观，没有玩法等级上限。
- 胜利、失败与重新开始流程。每局分数和局内武器升级独立计算，永久等级与最高分分别保存。

本版为 100 关单机原型，没有排行榜服务器、登录、广告、支付或在线联机。永久成长会改变后续出击的强度，真实难度和时长需结合不同等级的玩家试玩测量。

## 美术素材

六张 PNG 图集由用户提供并授权用于本游戏，原四张保存在 `assets/player.png`、`assets/enemies.png`、`assets/warships.png`、`assets/projectiles.png`，新增两张位于 `assets/expansion/enemy-variants.png`、`assets/expansion/fleet.png`。图像仅重新压缩 PNG 数据，解码后的 RGBA 与原图一致；六图合计约 6.76 MiB，新增两图约 3.02 MiB。素材在实际显示尺寸下足够清晰，未进行 AI 重绘或放大。用户的分类总览图用作外观参考，未把其中较小的带字图样直接替换游戏精灵。

我方十款、敌机十八款、战舰十四款已经接入；武器按当前局内等级使用普通弹、导弹、散射和光束外观，敌方使用红色弹及等离子弹。`src/assets.js` 维护尺寸、精灵源矩形和加载流程，渲染保留透明背景与宽高比；邻近精灵的包围盒重叠时，用同一比例绘制互不重叠的区域，避免相邻机头或尾焰串入。外观替换不改变碰撞与伤害规则，部分预留弹药图样尚未启用。六图加载完成前不可开局；素材缺失、尺寸错误或解码超过 15 秒会明确显示路径与错误并停止。

微信端新增图集放入 `fleet-assets` 资源分包，保留 `assets/expansion/game.js` 必需入口。启动先调用 `wx.loadSubpackage` 并显示下载进度，成功后才解码六图；失败、无效 API 或 30 秒超时均明确停止，不能静默省略新增舰队。主包与扩展包分别检查资源预算；浏览器从同一本地目录直接读取图片。

## 存档规则

- 永久经验使用 `fighter-era.profile` 键，结构为 `{ "version": 1, "totalXp": 0 }`。浏览器保存 JSON 字符串，微信保存对象；`totalXp` 必须是非负安全整数。
- 每次经验变化的 `progression` 事件会立即同步保存，不等待当前关卡结束，也不依赖下一帧或退后台回调。失败、回到机库或关闭前已保存的经验不会因重新开始而清零。
- 最高分继续使用旧键 `neon-wing.best-score`，以保留原型已有纪录；只有结算产生更高纪录时才保存。该旧键名是明确保留的兼容协议，不会影响「战机时代」品牌。
- 档案 JSON、版本或数值损坏时，会显示诊断并保留原数据；本次以初始档案临时游玩，不覆盖损坏记录。读写被禁用或保存失败时也会明确提示，本次经验可能无法在关闭后保留。
- 存档只在当前浏览器来源或当前微信存储环境内保留。清理应用数据、更换浏览器、设备或浏览器试玩端口不会自动同步档案；当前没有云存档。

## 微信开发者工具

1. 使用微信开发者工具导入本项目，项目类型选择「小游戏」。
2. 在开发者工具中选择当前账号可用的测试身份；正式发布前配置自己的真实小游戏 AppID。`project.config.json` 保留工具选择的身份，不要用占位值覆盖已配置的测试号或正式 AppID，测试身份不能代替正式发布身份。
3. 入口是根目录 `game.js`，竖屏设置在 `game.json`。不需要先运行浏览器服务器。
4. 在开发者工具及真机上检查触摸、屏幕比例、安全区域、前后台暂停和帧率。

微信入口使用 `wx.createCanvas`、`wx.getWindowInfo`、触摸事件、本地存储和生命周期 API。按实际屏幕尺寸等比缩放并保留黑边；输入通过同一变换映射到 405 × 720 的逻辑坐标。只跟踪第一根有效手指，按钮优先，点击按钮后继续按住不会误拖战机。

**微信版当前没有音频。已在微信开发者工具中完成编译、菜单渲染、点击出击、实战自动射击、战舰与 3 级战机外观变化检查；重新编译后菜单保留经验。真机兼容和平台发布审核尚未验证。** 已在模拟器实测单指相对拖动；多指、边缘触控仍需专项核验，开发者工具运行不能代替真机验证。当前运行环境如果缺少所需 API，将明确显示错误并停止，不伪装成功。

## 验证与排错

```sh
npm run check
npm test
```

`check` 检查 JavaScript 语法，`test` 运行引擎、渲染器、素材加载与微信 API 模拟测试。当前 81 项测试通过，覆盖真实波次调度到全部 100 个 BOSS、99 次过关升级、最终胜利、后期射速与弹幕数量边界、全部关卡的外观与背景，以及素材取图区域、分包加载进度、失败和超时。保留登机、弹射、救援、轰炸保留道具与单次奖励、存档和微信触摸检查。

100 关版已在浏览器实测新版开局、自动射击、救援、轰炸和暂停，控制台无警告或错误；微信开发者工具实测新版编译、100 关菜单、出击和自动射击。独立固定视觉场景检查第 50、99、100 关及战机、战舰两种 BOSS 形态，不代表实战通关。新增资源采用微信分包，按本地打包范围统计主包源文件约 3.85 MiB、扩展包约 3.02 MiB，均低于本项目各 4 MiB 的检查预算；实际上传包体由开发者工具确定。全关卡持续模拟未发现敌机或弹幕无限累积，实际手机帧率尚未测量。

援军与背景版已在浏览器实测援军出现、轰炸清屏、用尽按钮禁用和暂停，控制台无新增警告或错误；微信开发者工具实测两架援军及协同射击、轰炸清屏和正常获得升级经验。独立视觉场景用于检查三关背景、向下滚动和轰炸后保留增益道具，不代表真实战斗通关。背景不增加图片资源，固定复用 84 个星点及少量远景图形；实际手机帧率与耗电仍需真机测量。

此前动画版已在浏览器实测登机、暂停恢复、接入战斗及失败结算，微信开发者工具已实测登机动画、接入自动射击和「我方战机已被击败」结算提示。独立视觉场景复用实际渲染器，检查登机、跳入座舱、起飞、BOSS 警报、降落伞逃生和三种结果画面；这些固定场景不作为真实战斗通关证据。

此前图集版已在浏览器 390 × 844 和微信开发者工具中实测菜单、战机、敌机、子弹、自动射击和暂停，微信模拟器中单指相对拖动正常。浏览器此前已实测战斗升级、刷新保留等级与经验，以及 320 / 390 像素宽度布局。平台检查需覆盖开始、相对拖动、自动射击、暂停、升级、存档重载，以及 320 / 390 / 647 像素宽度下的布局。微信 API 模拟不能代替真实微信渲染或设备兼容验证；真机仍未验证。

浏览器控制台中可通过 `window.fighterEra.game` 检查状态、分数、经验、敌机与弹幕，通过 `window.fighterEra.renderer` 检查绘制对象。微信可查看 `GameGlobal.fighterEra`；`game.getProfile()` 返回可保存的档案快照。旧 `neonWing` 调试别名暂时保留兼容。严重错误会停止主循环并弹窗，日志包含当前状态、关卡和分数；存储或音频不可用会给出明确诊断，不会静默丢弃异常。仅记录状态、关卡、BOSS 登场/击败、登机/弹射、局内强化、升级和结算等关键事件，不逐次击杀刷日志。

## 文件

- `src/engine.js`：与平台无关的状态、碰撞、敌人及关卡逻辑。
- `src/renderer.js`：405 × 720 逻辑尺寸下的 Canvas 绘制与按钮布局。
- `src/assets.js` / `assets/`：用户提供的透明 PNG 图集、源矩形与严格加载流程。
- `src/browser.js`：浏览器输入、像素比例、音频、存储、暂停和可达性按钮。
- `index.html` / `style.css`：桌面飞行面板与手机适配。
- `game.js`：微信输入、屏幕映射、存储与生命周期。
- `server.js`：只监听本机的静态试玩服务器。
- `tests/`：无依赖自动化测试。
